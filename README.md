  # DOR Foundation v2 – Scholarship Management System (Teal Dark redesign)

  A redesigned copy of the DOR Foundation scholarship app. Features and flows are the same as the original; only the visual design changed.

  - Theme: Teal Dark (all styling lives in `src/styles/teal-dark.css`)
  - Demo login: any mobile number and any password work for students and volunteers. Admin opens directly.
  - Live at: https://gitforsoumen.github.io/dor-foundation-v2/
